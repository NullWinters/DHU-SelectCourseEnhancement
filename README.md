# 东华大学本科教务管理系统选课显示增强

油猴脚本，用于增强东华大学本科教务管理系统的选课体验。

## 适用页面

- 培养计划页面
- 课程分类查询页面
- 各院系开课情况汇总页面
- 其他专业选修课程页面
- 学生首页

以上页面在校内直连（`jwgl.dhu.edu.cn`）和校外通过 webvpn 代理（`webproxy.dhu.edu.cn/https/<token>/...`）访问时均可生效。

## 功能列表

### 培养计划页面追加教学大纲/教学日历按钮

在培养计划页面中，课程表格的「课程名称」列后会追加「教学大纲」「教学日历」两列，点击即可分别查看该课程的教学大纲与教学日历，无需额外操作。

同时统一了班次列表的入口：点击课程名称打开班次列表（原实现只挂在部分课程的课程编号上，没有链接的课程无法查看），课程编号不再响应点击，仅作普通黑色文本显示。

### 选课手册显示最新版本

点击选课手册按钮时，自动从教务处网站获取并显示2019级至最新年级的选课手册链接，替代系统默认的2018至2020级手册。

### 已修已选已通过课程查看班次列表

在培养计划、课程分类查询、各院系开课情况汇总、其他专业选修页面中，对于已修、已选或已通过的课程，点击课程编号或课程名称后仍可查看班次列表，系统会显示相应提示信息但不阻止查看。

### 各院系开课情况汇总页面支持"全校"查询

各院系开课情况汇总页面的"学院"下拉栏中，原本的"全校"选项在后端不返回任何课程，选择后表格会被静默清空。现在脚本会在前端并发请求下拉栏中每个学院的开课列表（6 路并发，约 1 秒完成），并按下拉栏顺序合并渲染，效果等同于查看全校开课情况。

同时，查询结果为空时会显示"未查询到课程"提示，不再静默清空表格；点击"课程名称""教学大纲"仍可正常查看班次列表与教学大纲。

### 删除选课注意事项按钮

自动移除培养计划页面中的选课注意事项按钮。

### 删除荣誉课程表格

自动移除培养计划页面底部的荣誉课程通识类和荣誉课程专业类表格。该处理仅针对培养计划页面中由 `selecthome.js` 生成的荣誉课程块，其他页面（如各院系开课情况汇总、其他专业选修）中名称含"荣誉课程"字样的课程不会被删除。

### 移除首页浮动的评教指南

自动移除学生首页上不停弹跳的"评教指南"图片（跳转 `evalHelp.jsp` 的浮动按钮），同时停止驱动它的定时器，避免无用计算。

### 兼容校外 webvpn 代理访问

校外访问时，URL 会变为 `https://webproxy.dhu.edu.cn/https/<token>/dhu/...`。脚本已为此追加对应的匹配规则，并做如下适配：

- 通过代理注入的 `vpn_rewrite_url` 判断当前是否处于代理环境，并按站点内路径（去掉 `/https/<token>` 前缀）执行原有的页面判断逻辑
- 获取选课手册时调用页面内的 `fetch`，由代理把站外地址改写为同源代理地址，避免跨域失败
- 手册链接沿用代理环境的地址改写，保证可在新标签页中打开

### 简化文化素质类课程数量提示

课程分类查询（文化素质类）页面顶部原本会显示"共有 N 门课，大英类同一级别不重复计算学分！新生不能选第1周开课课程！…"这类长文案，脚本会移除其中的说明文字（含随年级切换的两套文案），仅保留"共有 N 门课"，并让它另起一行居中显示在"文化素质类"标签下方。

## 安装方法

1. 安装油猴浏览器扩展
2. 在油猴中新建脚本
3. 将本脚本内容粘贴保存
4. 刷新教务系统页面即可生效

## 技术说明

- 使用unsafeWindow访问页面全局函数
- 使用MutationObserver监听动态加载内容
- 校内直连时使用GM_xmlhttpRequest跨域获取教务处数据，校外代理时改用页面内fetch（由代理改写为同源地址）
