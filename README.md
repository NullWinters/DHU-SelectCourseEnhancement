# 东华大学本科教务管理系统选课显示增强

油猴脚本，用于增强东华大学本科教务管理系统的选课体验。

## 适用页面

- 培养计划页面
- 课程分类查询页面
- 各院系开课情况汇总页面
- 其他专业选修课程页面
- 学生首页

以上页面在校内直连（`jwgl.dhu.edu.cn`）和校外通过 webproxy 代理（`webproxy.dhu.edu.cn/https/<token>/...`）访问时均可生效。

## 功能列表

### 培养计划页面追加教学大纲/教学日历按钮

在培养计划页面中，课程表格的「课程名称」列后会追加「教学大纲」「教学日历」两列，点击即可分别查看该课程的教学大纲与教学日历，无需额外操作。

同时统一了班次列表的入口：点击课程名称打开班次列表（原实现只挂在部分课程的课程编号上，没有链接的课程无法查看），课程编号不再响应点击，仅作普通黑色文本显示。

### 教学大纲/教学日历无内容时给出占位提示

并非所有课程都上传了教学大纲与教学日历，这类课程点击后原本会弹出一个空白弹窗（或残留上一门课程的内容），看不出是没材料还是接口出错。现在会在弹窗内给出明确的占位提示：主体为"该课程暂未提供教学大纲/教学日历"，若服务端带回了失败原因（例如 `[ERR-998]-其他异常`），再在其下补一行灰色小字说明。查询失败时同样显示占位提示而不是空白弹窗，并在下一次打开时重新尝试。

系统的材料接口 `/course/onlineViewNewBySftp` 在失败时返回的是一个单元素数组 `[{"msg":"[ERR-998]-其他异常","success":false}]`，而页面脚本按对象读取 `result.success`（得到 `undefined`）并把 `result.msg`（同样是 `undefined`）写进弹窗，这正是弹窗空白的成因。脚本因此整体替换了 `$.viewCourseMaterial`，直接对接该接口并自行判定与渲染。

弹窗底部的"下载为 Word 文档"按钮仅在确实取到内容时显示，占位提示状态下隐藏。

### 教学大纲/教学日历弹窗内可下载为 Word 文档

弹窗底部追加了"下载为 Word 文档"按钮，把当前预览的材料保存为 `.doc` 文件，双击即可用 Word/WPS 打开并保留原有排版（字体、字号、居中、表格等）。

文件名形如 `课程名称_教学大纲_课程代码.doc`；在拿不到课程名称的页面（如各院系开课情况汇总）降级为 `类型_课程代码.doc`。课程名称通过课程代码在同一页面已有表格中反查得到，反查时会跳过弹窗自身的内容——材料 HTML 里往往也带有课程代码表格，否则会取到材料内部的名字。

导出内容做了这样的处理：

- 服务端返回的是 Aspose.Words/Aspose.Cells 等工具转换出的 HTML 片段，其中 `<link>` 指向站内 CSS、`<img>` 指向已失效的图片地址（实测全部 404）。保存前会移除全部 `<link>`、把非 `data:` 协议的 `<img>` 替换为灰色「【图片缺失】」占位文字，并剔除带 `charset`/`http-equiv` 的 `<meta>`。
- 这批材料普遍声明 `gb2312`，但接口返回的字节实际是 UTF-8。保存时统一改写为 `<meta charset="utf-8">` 并写入 UTF-8 BOM，Word 以 BOM 为准判定本地 HTML 编码，中文不会乱码。

### 培养计划页面展开查看"其它课程"

培养计划表格下方追加了一个"展开其它课程"按钮，默认折叠，点击后才渲染并追加到培养计划表格末尾，再次点击可收起。若没有这类课程，按钮不会显示。

"其它课程"指选了但不计入培养计划的课程，服务端渲染的培养计划表格里没有它们，原本只能在学生成绩查询页面看到。展开后会在表格末尾追加一个"其它课程 / 选修课"分类，其下的课程行排版与培养计划中的课程行一致，显示课程编号、课程名称、学分与所在学期，已选但未出成绩的显示"已选"；点击课程名称同样可以打开班次列表，也带有"教学大纲""教学日历"两列。

数据直接复用培养计划页面自身的 `initTSCourses` 接口，其中的 `otherScore` 字段虽然会被服务端返回，但页面脚本只使用了 `tsCourses`，这部分数据被丢弃。脚本在页面加载时取回并判断数量，只有存在其它课程时才插入按钮；此后每次点击展开都会重新请求一次，避免列表过期，若此时已没有其它课程则连按钮一起移除。

### 培养计划页面「已选」改为「退课」

培养计划表格中学期列的「已选」标记被替换为可点击的「退课」链接，点击并确认后会退掉该课程。其它课程中已选未出成绩的行同样适用。

培养计划表格里没有班次信息，脚本先向 `initSelCourses` 查询本学期已选课程，按课程编号找到对应班次号，再调用与课程删除页面（`toSSC`）删除按钮相同的 `cancelSC` 接口（`cancelType=1`）。退课会释放名额且可能被他人占用，因此点击后会先弹窗确认；请求失败时提示原因并将链接恢复为可点击状态。退课成功后，脚本就地清掉该课程所在学期列的标记，并在其它课程处于展开状态时重新查询并重绘，避免列表与选课状态不一致。

### 培养计划页面底部追加超星学习通自选课程入口

培养计划表格底部追加了一个居中的"超星学习通自选课程"链接，点击后在新标签页打开 `https://dhu1.fanya.chaoxing.com/portal`，方便直接进入学习通查看自选课程，无需再手动输入网址。

学习通是站外系统，与教务系统之间只有链接跳转、没有数据交换，因此这里只插入一个链接，不涉及任何接口调用。链接追加在课程表格所在容器的末尾，即正文最底部，位于"展开其它课程"按钮之下、页脚之上；校外通过代理访问时沿用与选课手册链接相同的地址改写规则。

### 选课手册显示最新版本

点击选课手册按钮时，自动从教务处网站获取并显示2019级至最新年级的选课手册链接，替代系统默认的2018至2020级手册。

### 已修已选已通过课程查看班次列表

在培养计划、课程分类查询、各院系开课情况汇总、其他专业选修页面中，对于已修、已选或已通过的课程，点击课程编号或课程名称后仍可查看班次列表，系统会显示相应提示信息但不阻止查看。

### 已选课程在班次列表内直接换课

系统原本要求先退课，才能通过选课序号重新选择同一门课。现在若课程已选，在班次列表中点击另一个选课序号的"确认"，会弹出风险提示，确认后自动执行"退课再选课"：先退掉当前班次，再提交新班次。

该功能在培养计划、课程分类查询、各院系开课情况汇总、其他专业选修四个页面上均已生效。

由于退课与选课之间存在时间差，新班次名额可能已被他人占用。因此脚本会：

- 弹窗告知当前班次信息（选课序号、班次、教师、时间、教室）与名额被占的风险；
- 在退课前先调用 `scConflictCheck` 检查冲突，冲突确认的步骤提前到退课之前，避免用户在退课之后取消而导致课程丢失；
- 若新班次提交失败，自动尝试重新选回原班次，并提示"换课失败，已自动重新选回原班次"；
- 若原班次也无法选回，则提示"请立即手动重新选课"。

若该课程并未选中，则不弹窗、不走换课流程，直接按原有逻辑选课。选课状态每次都重新向 `initSelCourses` 查询，不使用缓存，以免在其他页面退课/选课后产生过期判断。

### 班次列表弹窗表格居中排版

班次列表弹窗中的班次表格原本表头居中、数据行左对齐，脚本统一改为居中对齐，与该弹窗的其余内容排版一致。

### 各院系开课情况汇总页面支持"全校"查询

各院系开课情况汇总页面的"学院"下拉栏中，原本的"全校"选项在后端不返回任何课程，选择后表格会被静默清空。现在脚本会在前端并发请求每个开课部门的开课列表（6 路并发），并合并渲染，效果等同于查看全校开课情况。

部门列表不取自下拉栏，而是直接查询 `/dhu/common/orgnSS`。下拉栏由 `getAllOrgnizations({isAcademy:true})` 填充，只会列出 44 个院系，而该接口在 `isAcademy` 非 1 时会返回全部 95 个部门。只按下拉栏聚合会漏掉这些隐藏部门开设的课程（例如团委的"大学生社会实践导航：理论与实务"），因此改用完整列表，无课程的部门在合并时自然被跳过。

同时，查询结果为空时会显示"未查询到课程"提示，不再静默清空表格；点击"课程名称""教学大纲"仍可正常查看班次列表与教学大纲。

### 删除选课注意事项按钮

自动移除培养计划页面中的选课注意事项按钮。

### 删除荣誉课程表格

自动移除培养计划页面底部的荣誉课程通识类和荣誉课程专业类表格。该处理仅针对培养计划页面中由 `selecthome.js` 生成的荣誉课程块，其他页面（如各院系开课情况汇总、其他专业选修）中名称含"荣誉课程"字样的课程不会被删除。

### 移除首页浮动的评教指南

自动移除学生首页上不停弹跳的"评教指南"图片（跳转 `evalHelp.jsp` 的浮动按钮），同时停止驱动它的定时器，避免无用计算。

### 兼容校外 webproxy 代理访问

校外访问时，URL 会变为 `https://webproxy.dhu.edu.cn/https/<token>/dhu/...`，其中 `<token>` 是代理对目标站点加密后的标识。脚本已为此放宽匹配规则，并做如下适配：

- 匹配规则同时接受 `webproxy.dhu.edu.cn` 与 `webvpn.dhu.edu.cn`（同一套代理服务的两个域名），`/https/<token>` 前缀可有可无，代理调整地址形式后无需改动脚本
- 以地址中的 `/https/` 前缀判断代理环境（代理注入的 `vpn_rewrite_url` 仅作兜底信号，避免代理脚本晚于本脚本加载时误判为直连），并按站点内路径（去掉 `/https/<token>` 前缀）执行原有的页面判断逻辑
- 获取选课手册时调用页面内的 `fetch`，由代理把站外地址改写为同源代理地址，避免跨域失败
- 手册链接沿用代理环境的地址改写，保证可在新标签页中打开

### 简化文化素质类课程数量提示

课程分类查询（文化素质类）页面顶部原本会显示"共有 N 门课，大英类同一级别不重复计算学分！新生不能选第1周开课课程！…"这类长文案，脚本会移除其中的说明文字（含随年级切换的两套文案），仅保留"共有 N 门课"，并让它另起一行居中显示在"文化素质类"标签下方。

### 选课页面左上角追加课程表侧边栏

在 `toSH`、`toSCC`、`toSelectByOrgn`、`toOEC` 四个选课页面的左上角（页头下沿）追加一个"课程表"把手，点击即可滑出侧边栏查看课程表，方便选课时确认某个时间段是否已经排课。

- 默认收起，只保留把手；再次点击把手或面板右上角的收起按钮即可折叠
- 学期下拉取自 `/common/semesterSS`，默认选中上次查看的学期，没有记录时选中当前学期
- 课表由 `/StudentCourseTable/getData` 渲染，与课程表页面（`StudentCourseTable/toPage`）用的是同一组接口，因此不必再打开课程表页面
- 课表下方按同样的口径列出该学期**没有设置上课时间的课程**（期末实践类、暑期课程等），数据来自 `getData` 返回的 `list`
- 面板高度跟随课表内容，不会在课表下方留下一大片空白；内容超出可视区域时只在面板内部滚动
- 面板右边缘可拖动调整宽度，宽度会记入 `localStorage`（`dhuCourseTableWidth`），下次打开时沿用

## 安装方法

1. 安装油猴浏览器扩展
2. 在油猴中新建脚本
3. 将本脚本内容粘贴保存
4. 刷新教务系统页面即可生效

## 技术说明

- 使用unsafeWindow访问页面全局函数
- 使用MutationObserver监听动态加载内容
- 校内直连时使用GM_xmlhttpRequest跨域获取教务处数据，校外代理时改用页面内fetch（由代理改写为同源地址）
