# 东华大学本科教务管理系统选课显示增强

油猴脚本，用于增强东华大学本科教务管理系统的选课体验。

## 适用页面

- 培养计划页面
- 课程分类查询页面
- 各院系开课情况汇总页面

## 功能列表

### 课程名称点击查看教学大纲

在培养计划页面中，点击任意课程名称可直接查看该课程的教学大纲，无需额外操作。

### 选课手册显示最新版本

点击选课手册按钮时，自动从教务处网站获取并显示2019级至最新年级的选课手册链接，替代系统默认的2018至2020级手册。

### 已修已选已通过课程查看班次列表

在培养计划、课程分类查询、各院系开课情况汇总页面中，对于已修、已选或已通过的课程，点击课程编号或课程名称后仍可查看班次列表，系统会显示相应提示信息但不阻止查看。

### 删除选课注意事项按钮

自动移除培养计划页面中的选课注意事项按钮。

### 删除荣誉课程表格

自动移除培养计划页面底部的荣誉课程通识类和荣誉课程专业类表格。

## 安装方法

1. 安装油猴浏览器扩展
2. 在油猴中新建脚本
3. 将本脚本内容粘贴保存
4. 刷新教务系统页面即可生效

## 技术说明

- 使用unsafeWindow访问页面全局函数
- 使用MutationObserver监听动态加载内容
- 使用GM_xmlhttpRequest跨域获取教务处数据
